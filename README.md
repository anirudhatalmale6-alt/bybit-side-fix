# P2P Arbitrage Bot

Асинхронный каркас P2P-бота под Python 3.9+ для Bybit и Binance.

Что уже есть:

- режим `Bybit first`: биржи включаются через `P2P_PLATFORMS`, по умолчанию только `BYBIT`
- сканер P2P-объявлений по `USDT/<список fiat из P2P_FIATS>`
- анализатор внутриплатформенного, межплатформенного и кросс-валютного спреда
- SQLite для сырых ордеров, возможностей и сделок
- Telegram-команды и алерты
- Bybit P2P order manager с ручным подтверждением сделки через Telegram
- risk guard, daily limits и kill switch
- strategy engine для автосоздания и автоподдержания `buy/sell` P2P ads на Bybit

Что важно учитывать:

- Bybit P2P order management работает только с advertiser-доступом и API-правами на P2P.
- Binance public search endpoint для P2P объявлений не является официально задокументированным market-data API. Поэтому он вынесен в отдельный клиент и легко меняется через конфиг.
- Автоподтверждение получения фиата не реализовано и не должно включаться автоматически.
- Исходящий фиатный платёж при покупке USDT через P2P всё равно остаётся ручным действием. Бот может прислать алерт и по кнопке отметить ордер как `paid`, но сам банковский перевод не делает.

## Быстрый старт

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

```bash
pip install -e .
```

3. Скопируйте `.env.example` в `.env` и заполните ключи.
   Для старта только на Bybit оставьте `P2P_PLATFORMS=BYBIT`.
   Когда будете готовы добавить Binance, переключите на `P2P_PLATFORMS=BYBIT,BINANCE`.
4. Запустите:

```bash
python -m p2p_bot.main
```

## Основные команды в Telegram

- `/status`
- `/pause`
- `/resume`
- `/report`
- `/spreads`
- `/config`
- `/set_spread EUR 1.5`
